---
name: Separate classroom setup
description: The Desk Planner requirement to separate class configuration from classroom seating.
---

Keep class name, seating format, roster traits, and separation rules on a page distinct from the classroom map. The app opens to a general tools hub; teachers choose a class before opening its planner. In seating diagrams, students sit around a recognizable shared tabletop rather than appearing as a list inside a box.

**Why:** The user explicitly asked for a general Desk Planner entry point, class-specific setup followed by an accessible planner tool, separate trait/rule editing, and actual desks rather than a column of students labeled as a desk.

**How to apply:** Keep future roster, trait, and rule controls on class setup. Keep seating plans scoped to a chosen class and show students in distinct seats arranged around the table surface.
